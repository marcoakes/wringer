## The question, and why it is worth asking without the tool

> For each part of this change, does the evidence notice if it goes away?

The window's own diff against `302eb35` is 18 files, +1348/−113, and touches no
`src/` at all — it is guards and the documents they hold. Twenty-one units:
nine document corrections, and twelve mutations of the derivations the window
introduced, each mutation reverting a derived scope to **the hand-kept list it
replaced**. That mutation is the point: it is the QUICKSTART defect, aimed at
the window that exists to remove the QUICKSTART defect.

The evidence set is the guards this change touched — `test_docs`,
`test_doctor`, `test_neutrality`, `test_security_isolation_ledger`, the drive
and board suites — not the whole suite. Same scoping decision the spec makes,
for the same reason: the question is *does the evidence notice*.

### The finding, stated plainly

**Nine scopes were derived and only four had a guard.** `runbooks()`,
`docs_with_doctor_output()`, `is_capture()` and `declares_itself_preserved()`
each had a test asserting the derivation is wider than the list it replaced —
and each of those four went red under mutation. The other five had nothing, so
reverting them to their hand-kept tuples reddened **nothing at all**.

A later window could have narrowed every one of them back, with the suite
green the whole way, and the commit message would have read like a tidy-up.
That is precisely the defect the window was fixing, reproduced inside the fix,
and no amount of reading the diff would have shown it — the four guards that
worked and the five that did not look identical in review.

The last row is an honest limit rather than an excuse, and it has a
consequence worth writing down: in this repository the guards ARE the product
surface for documents, so a window that loosens `assert X` to `assert True or
X` has nothing stopping it. What IS guardable is the logic behind the assert,
and both hatches now have it — `_NAMES_IT_TO_WARN` must refuse to license a
bare instruction to run the broken command, and a correction 2000 characters
away must not license the stale claim beside it.
