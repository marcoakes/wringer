# DRIVE, driven both ways — 2026-08-17

*Unedited console. The same project, the same answers, twice: once by a person
at a terminal, once by something reading `--emit json` the way a coding agent
would.*

## The decision this films

SPEC_DRIVE_V0 §9 question 4, decided by Marc on 2026-08-17: **the transport is
the PM's own coding agent.** They already have one — the install page is a
prompt you paste into it — so the interface exists and building a second would
answer a question nobody asked. A local web page is forbidden anyway: B1's
test names `http.server` among the banned dependencies.

**The agent is a transport, not a translator.** Every sentence below came from
the engine or the board, verbatim. Section C is why that is checkable rather
than asserted: the two runs produce a **byte-identical** `wringer.spec.yaml`.

## What to look at

- **A** — a person types answers. No agent anywhere.
- **B** — the same run, one JSON object per line. Same text, same order, same
  interlocks. It is not a second implementation: both render the same `Step`
  objects, which is the only reason they cannot drift into two products.
- **C** — **byte-identical output from both transports.**
- **D** — saying **no** exits 0 and changes nothing. Declining is not an error,
  and the answer to the question is still written, because answering and
  approving are different acts.
- **E** — a stream with **nobody behind it takes no default**. A CI job or a
  careless script gets a stop and a sentence, not an approval nobody gave.

## What driving it FOUND

**The plan told a PM "NOTHING CHECKS THIS YET" about a criterion a gate was
already bound to.** `interview.plan` read `wringer.gates.yaml` — where a
drafter PROPOSES gates — and never `.wringer.yaml`, where a human INSTALLS
them and where the only ones that actually run live.

A false sentence, on the page a PM approves from, to the reader least able to
check it. Fixed: both files are read, the installed binding wins, and a
proposal now says *"proposed, not installed yet"* rather than reading as a
check somebody agreed to run.

## What this does NOT yet do

Steps 7 to 10 — installing approved gates, running the loop, delivering, and
rendering the board — are **not built**. This films steps 0 to 6: prose in,
questions answered, plan rendered, approval taken. The DONE box in
SPEC_DRIVE_V0 §8 is the list, and no number is claimed for §6's PM-mode
quickstart because nothing has measured one.
