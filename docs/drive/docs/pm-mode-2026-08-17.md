# PM mode, measured — 2026-08-17

*SPEC_DRIVE_V0 §6. The target is stated only after it has been measured once;
this is the once. No number appeared in any claim before this file existed.*

## The number

**27 seconds**, from a prose document to the first honest green, with the
operator answering ten questions and editing no file.

In one sentence a PM could read: *you write down what you want in ordinary
prose, answer about ten questions, and half a minute later a page tells you
what was built, what was proved, and what still needs you.*

**Reconciliation note, added 2026-08-18. No number in this file has been
changed, and none may be.** This document states its number three ways — **27**
above, **27.2s** and **27.5s** in the table below — in a file whose stated
purpose is that the number is said only once it has been measured. They are
one measurement, and this is the sentence that was missing: **27.5s is the
total wall clock**, **27.2s is the time to the first honest green**, and
**27 is 27.5 rounded for the headline**. A reader counting found three numbers
where the document promised one; that is a real defect and it was this
document's. The repair is a dated note rather than an edit, because a capture
is evidence and evidence is corrected beside itself.

## What it measures, precisely

Wall clock from `wringer-drive run PRD.md` in a repository with **no
`.wringer.yaml`, no spec and no plan**, to the loop reporting `converged`.
Every step in SPEC_DRIVE §2 ran: the PRD was copied inside, the workspace was
generated, the spec was drafted by a model from the prose, the drafter's
questions were answered, the plan was rendered and approved, the proposed
gate was shown as a diff and installed on a yes, the loop ran, the board was
rendered, and the handover was refused.

The operator opened no editor and typed one command.

| | |
|---|---|
| total wall clock | **27.5s** |
| to the first honest green | **27.2s** |
| answers from the operator | **10** (3 setup, 5 the drafter's, 2 approvals) |
| files the operator edited | **0** |
| the drafting endpoint | `https://api.anthropic.com/v1/chat/completions`, `claude-sonnet-4-6` |
| the worker | an ACP agent, **uncontained** — see below |
| cost | about $0.10 across two model calls |

**22.4 of the 27.5 seconds is the drafting call.** The rest of the chain —
nine steps, a real repair loop and a rendered board — is under five seconds.
That ratio is the honest headline: PM mode is not slow, and what a PM waits
for is a model reading their document.

## Why the green is honest

A gate green at birth evidences nothing, so "first green" would be a
meaningless number. This one is red first and the record says so, in the two
run bundles the loop wrote:

```
20260817-173931-ba3d   {'result': {'status': 'failed', 'failed_gate': 'test'}}
20260817-173935-d100   {'result': {'status': 'passed', 'failed_gate': None}}
```

Between them the worker changed `src/report.py`, thirteen lines. The check it
made pass — `tests/test_csv_export.py` — was committed **before** any of the
work, by an engineer, and fails against the repository as it stood: a check
that arrives with the work cannot evidence the work.

## What drove it, by name

**Drafting** was a real endpoint and a real model:
`https://api.anthropic.com/v1/chat/completions` with `claude-sonnet-4-6`. The
spec in this capture — six criteria, one of them `human: true`, and the
questions the operator answered — was written by that model from the prose,
not fixtured.

**Building** was a minimal ACP agent written for this capture
(`acp_model_agent.py`), which speaks real JSON-RPC over stdio to
`wringer.acp` and whose `session/prompt` turn asks the same endpoint for the
repair and writes it back through the client's own `fs/write_text_file`. The
wire is the one `tests/fake_acp_agent.py` already proved against the engine;
only the turn is different.

**It is not a vendor agent, and this repository still has not driven one.**
Gemini CLI, Goose and Kimi are not installed on this runtime and none was
exercised. Nothing here licenses a claim about any of them, and the ACP
census keeps its "not exercised in this repository" rows.

**The worker ran UNCONTAINED.** No containment was declared and none was
measured, so nothing here may be read as a containment result. `podman` is
running on this machine, so the ceiling is untested rather than known —
that is a gap, stated, not a finding.

## The ending, which is the product working

The run exits non-zero. `wring deliver` refused, and the refusal reached the
operator as the board's sentence rather than an exit code:

```
The handover is being held because at least one requirement cannot show its proof.
See the cards above — each one holding this up says what it needs.
```

with the engine's own words carried verbatim beneath it — two criteria
unevidenced, one because its gate was born green and one because a person has
not answered it. Both are true, and neither is something the verb may resolve.

**A PM-mode number that ended in a delivered merge request would be the worse
result.** The chain was asked to hand over work whose proof it could not show,
and it said no.

## What this does NOT claim

- **Nothing about wrong fixes.** Q1's ceiling binds every sentence here: a

  not certify that the change is the one anybody intended.
- **Nothing about containment**, per above.
- **Nothing about a second run.** This is one measurement of one project on
  one machine. The drafter is non-deterministic — it asked a different set of
  questions on each of the four runs this window drove — so the number will
  move, and the ten-answer count with it.
- **Nothing about a PM without a coding agent.** This was driven through

## What driving it FOUND

Two live defects, neither found by reading.

**A PM answering "yes" silently wrote a boolean and broke their own spec.**
`wringer_board.interview._scalar` decided quoting from which characters were
in the text; YAML's plain scalars are not decided by characters. `yes`, `no`,
`true`, `off`, `null`, `~`, `1.5`, `12`, `2026-08-17`, `Yes` and `NO` all
reparse as something other than a string, and `wring plan` then refused the
PM's own spec with *"'answer' must be a string"* — a message about types, to
the reader least able to act on it. Fixed in `wringer-board` at `fe53027` by
asking the loader instead of reasoning about the text.

**`wring spec --send` cannot reach any current-generation Anthropic model.**
`spec.build_request` always sends `temperature: 0`, and Claude Opus 5, Opus
4.8, Opus 4.7, Sonnet 5 and Fable 5 all reject it —
`` `temperature` is deprecated for this model ``, HTTP 400, before a single
token is drafted. This capture used `claude-sonnet-4-6`, which still accepts
it. That is a finding against the engine and is recorded, not fixed here: it
is a core change, and this window had no licence for one.
