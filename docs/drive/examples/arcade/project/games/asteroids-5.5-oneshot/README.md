# Asteroids 5.5 Oneshot

Browser-based arcade clone inspired by the 1980 Atari classic, implemented as a single static HTML/CSS/JS site with all graphics drawn on `<canvas>`.

## Live URL

https://marcoakes.github.io/asteroids-5.5-oneshot/

## Controls

- Left / Right Arrow: rotate
- Up Arrow: thrust
- Space: fire
- Shift or H: hyperspace
- Enter: start from title screen or restart after game over

## Notes

- Three starting lives
- Extra life every 10,000 points
- Large, medium, and small asteroids split progressively
- UFOs appear during play, with small UFOs aiming at the ship

## Local Run

Open `index.html` in a browser, or serve the repo root with any static file server.
