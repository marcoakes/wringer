# People lose their place in the cabinet

We put four games behind one page so people could wander between them, and
that part works. What doesn't work is coming back.

Every visit starts from the same cold grid of four tiles in the same order. If
you played two rounds of pinball last night, the cabinet has no idea. You have
to remember which one you were in the middle of and go and find it again, and
at four games that's mildly annoying — at twenty it will be the reason people
stop opening it at all. Two of the folk who tried it said the same thing
unprompted: it doesn't feel like *mine*.

What we want is for the cabinet to remember what you have been playing and put
it in front of you. When you come back, the games you actually played recently
should be right at the top, most recent first, under a heading that makes it
obvious they're yours rather than a recommendation. The full set of games
should still be there underneath, exactly as it is now — this is about adding a
shortcut, not hiding anything.

A few things we've already decided, because we got them wrong on paper first.
Playing something again should move it back to the front rather than listing it
twice. Only the last handful should show — three feels right; a long list is
just the grid again. And it has to survive closing the tab, because the whole
point is what happens when you come back tomorrow.

The one thing I really don't want is for this to be able to break the cabinet.
If whatever remembers all this gets into a state we didn't anticipate, or we
retire a game that somebody has played, the page must still open and every game
must still start. A shortcut that can take the arcade down is worse than no
shortcut.
