# Adoption implementation candidate — 28 September 2026

The rebuild is implemented in the existing Bun/TypeScript repository as a local
`1.0.0-alpha.20` candidate based on `7f4cc542fd1149c00a3be0ee8949c895b95ef0c3`.
The source is uncommitted. No tag, push, public release, model call, account change
or actual human acceptance is implied.

The product has two explicit modes, reusable workspaces and immutable jobs,
finite execution grants, typed proposal correction, source-bound evidence and
review, separate Send, retained-state recovery, diagnostics, scoped client
adapters, and a single executable with compatibility aliases. Archive/installer,
npm, Homebrew, Action, registry and native image machinery are prepared. There
are 179 schema files; published schema bytes and the historical corpus remain
unchanged. Current guides, CLI reference, shared skill and three examples are
included. Optional native confirmation stays a separate capability build and
does not enable protected mode.

The full integrated suite passed 1,162 tests with zero failures and one explicit
Linux DAC skip on macOS. Compiled routes, portable corpus, local delivery, CLI
reference, examples, all six PM rehearsals and the additional browser/connection
journeys passed. These use real Git, processes and Chromium where described;
delegated roles and operator decisions in rehearsals are synthetic. Later
integration repairs have separate targeted and controlled-reversion checks.
The final report identifies every applicable measurement and exact artifact.

The real archive migration procedure installs the intermediate alpha19 candidate,
creates an unapproved job through its working MCP path, upgrades to alpha20,
checks unchanged job bytes and authority, refuses incompatible older-schema
rollback, uninstalls, and reads retained work with the extracted candidate.
Compatible rollback and interrupted switching/removal have separate filesystem
regression tests. The intermediate archive's broken default CLI job path remains
a recorded failure; the current implementation has a tested repair.

The final local handoff is `build/rebuild-candidate/`: native archive, flat
bootstrap binary, checksums, distribution/dependency inventory, private fixture
channel packages/formula/registry metadata, exact claim report, sanitized captures,
T01–T26 results and a machine-readable measurement index. The accompanying
`IMPLEMENTATION_REPORT.md` and `REPORT.json` provide computed final digests and
completion axes. An absent or failed report cannot qualify an artifact.

Implementation is distinct from platform qualification. macOS CLI/verification
engineering is measured. Native Linux, real Apple Container/gVisor isolation,
Homebrew installation, complete named-client journeys, genuine human acceptance,
independent newcomer usability and public installation remain unmeasured here.
Their executable procedures and prerequisites are retained in
[acceptance](ACCEPTANCE.md), [live acceptance](LIVE_ACCEPTANCE.md) and
[external actions](EXTERNAL_ACTIONS.md).

Failed reports remain dated. No previous failure was converted to a success.
Neither checksums nor scripted review authenticate human identity. Current
cooperative-local review and trusted-local verification limits remain explicit.
