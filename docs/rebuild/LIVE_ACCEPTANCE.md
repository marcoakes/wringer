# Live acceptance procedure — not yet executed

Run separately for Claude Code, Codex CLI and Codex desktop, on each platform
claimed. Before work, record exact client/runtime/image/binary versions, artifact
digest, task, source, role models, finite call/time/cost allowance and actor. Obtain
real provider and service permissions separately. No account/key values enter the
report. A failed or repaired attempt retains its original outcome.

1. Start from the shipped README/skill. Record warm/cold installation, download,
   connection and human-attention timings separately; ten/five-minute adoption
   targets are measurements, not promises.
2. Install the exact candidate; inspect/apply scoped configuration while preserving
   unrelated entries. Observe named-client tool and skill discovery explicitly.
3. Select verification or delegation. For delegation provision/measure containment
   without model prompts, then select explicit role models. Record both billing
   lanes (existing assistant and managed roles); missing usage remains unknown.
4. Submit the supported original request. Deliberately produce one invalid mutable
   proposal field, repair it using the returned error, and resolve a question on
   the same lineage. Inspect the pinned source/acceptance/limits. The person approves.
5. Perform meaningful work. Disconnect the coding client once while an operation
   is running. Reconnect and observe the same job/reservation; do not allocate a
   replacement request. Exercise reload/expiry and one stale tab.
6. The person inspects actual output and requests one correction in their words.
   Observe source advancement, checks and fresh display. Missing/failed display
   must keep acceptance unavailable. The person records their real review.
7. Decline Send once; verify no publication occurred. Then authorize the exact
   candidate/destination, observe the branch/PR fact and audit from a fresh clone
   without controller/provider access. A merge/deploy requires its own authority.
8. Create a second job on later source and verify earlier records/grants remain
   unchanged. Stop, close the owner, preview upgrade/rollback and remove only owned
   client configuration. Inspect retained evidence after uninstall.

Retain a sanitized report of each observation, source/artifact identities, actual
actor, known/unknown cost, timings and unsuccessful paths. Never publish private
connection records, page links, screenshots with secrets or raw provider traces.
Keep engineering fixtures, owner acceptance and independent newcomer attempts in
separate rows. An implementation repair ends a blind attempt; start the next with
a newly identified candidate. Scripted decisions cannot satisfy human acceptance.
