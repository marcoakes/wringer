# Build our Reports workspace

Use the supplied design and the components already in this repository to build
a calm, clear Reports workspace. I need to find the right report quickly, without
learning a technical dashboard.

Load the reports from the supplied local report data. Show each report's title,
owner, date and status. Search should narrow the reports by title; the status
filter should work alongside search. Opening a report should show its summary
and a clear way back. If nothing matches, explain that and offer a reset.

It must work by keyboard, have labelled controls and fit a phone without sideways
scrolling. Reuse the existing button, status and layout components and the design
tokens; do not replace the design system. Do not add a login, external service or
new dependency.

Before handing it over, show me desktop and mobile output next to the approved
design. I will decide whether the layout, hierarchy and overall feel are right.
If I ask for a correction, keep my words and show me the changed result. Ask me
separately before sending the finished branch and its handover proof.
